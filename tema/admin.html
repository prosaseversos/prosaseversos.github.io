Painel de escrita

Para escrever aqui, o navegador precisa de um token do GitHub. Ele fica guardado só neste aparelho e nunca sai daqui.

  1. Abra github.com/settings/personal-access-tokens/new (logado como prosaseversos)
  2. Repository access → Only select repositories → prosaseversos.github.io
  3. Permissions → Repository permissions → Contents: Read and write (e, se quiser ver o andamento da publicação, Actions: Read-only)
  4. Escolha a validade, gere e cole abaixo

Peça o acesso mínimo: só este repositório, só Contents. Assim, se o token vazar, o alcance dele é um repositório de poesia que já é público — e você pode revogá-lo a qualquer momento na mesma página onde o criou.
